Sincronizzazione fra dispositivi

Con GitHub (consigliato): crea un repository privato (es. bjcp-dati), incolla qui il suo indirizzo e nel secondo campo un token con permesso di scrittura sui contenuti. I dati finiscono nel file bjcp-dati.json di quel repository. In alternativa funzionano un Cloudflare Worker (con passphrase) o un archivio JSON Blob (in sola lettura).
